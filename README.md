## The entry

One letter: **Y** — for *yawning*.

The whole day was one long yawn: jaw-cracking, eyes-half-shut,
coffee-not-working yawns from morning to night. It is vivid (everyone can
picture it at once), funny (the most relatable kind of tired), and true
(a real sleep-deprived day, not a performance). Y is the only honest
initial for it — no other letter starts the word, and no sharper Y-word
for a day exists.

## How it works

`main.ts` (Node 22+, standard library only, no network) writes exactly one
character, `Y`, with no trailing newline, to `/output/entry.txt` — the
gate requires 1 to 1 characters.

```sh
node main.ts
cat /output/entry.txt   # Y
```
